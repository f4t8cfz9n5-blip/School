# منصة المؤشرات الذكية للمخالفات المدرسية

منصة لتحليل بيانات مخالفات الطلبة المستوردة من بوابة سلطنة عمان التعليمية، وترتيب أولويات التدخل تلقائيًا للأخصائي الاجتماعي.

## يعمل فورًا بدون إعداد (وضع البيانات التجريبية)

```bash
npm install
npm run dev
```

يفتح التطبيق ببيانات تجريبية (Mock Data) محفوظة محليًا في المتصفح (localStorage)، فتقدر تجرّب كل الصفحات فورًا قبل ربط Firebase.

## ربط Firebase (لتفعيل الحفظ الحقيقي)

1. أنشئ مشروع Firebase جديد منفصل (Firestore + Authentication).
2. فعّل Firestore وAuthentication (Email/Password) من لوحة Firebase.
3. انسخ إعدادات المشروع (Project settings → SDK snippet → Config) وضعها في ملف `.env.local` (انسخ `.env.example` وعبّئه).
4. ارفع قواعد الأمان: `firebase deploy --only firestore:rules` (أو ألصقها يدويًا من ملف `firestore.rules`).
5. حاليًا الحفظ يتم في `localStorage` عبر `src/hooks/useAppData.ts` — هذا الملف هو نقطة الاتصال الوحيدة بالبيانات في كامل التطبيق، بحيث يسهل استبدال الدوال بداخله باستدعاءات Firestore الحقيقية (`addDoc`, `onSnapshot`, إلخ) دون لمس بقية الصفحات.

## النشر على Cloudflare Workers

```bash
npm run build
npx wrangler login
npx wrangler deploy
```

سينشر التطبيق على `<اسم-المشروع>.<subdomain>.workers.dev`. يمكن ربط نطاق مخصص لاحقًا من لوحة Cloudflare.

## استيراد بيانات المخالفات (PDF)

من صفحة **استيراد البيانات**:
1. صدّر تقرير "كشف تسجيل مخالفات الطلبة" كملف PDF من البوابة.
2. ارفعه — تقوم المنصة باستخراج الصفوف تلقائيًا (اسم الطالب، الصف، الشعبة، التاريخ، رقم المخالفة، الفئة، القرار).
3. **راجع الجدول قبل التأكيد.** استخراج الجداول العربية (RTL) من ملفات PDF تخميني وليس مضمونًا 100%، خصوصًا إذا اختلف تنسيق تصدير البوابة عن العيّنة المستخدَمة أثناء البناء. عدّل أي خلية يدويًا قبل الضغط على "تأكيد الاستيراد".
4. الأسطر التي يتطابق رقم مخالفتها مع مخالفة محفوظة مسبقًا يتم تجاهلها تلقائيًا (كشف تكرار).

## بنية المخالفات المعتمدة

مصدرها لائحة شؤون الطلاب بالمدارس الحكومية (الفصل السادس، المادتان 39 و40) وهي مُدارة كبيانات في `src/data/violationCategories.ts`. بعض بنود المستوى (د) الأولى في كل قائمة فرعية قد تحتاج مراجعة نهائية مقابل النص الرسمي الكامل.

## أوزان الأولوية

قابلة للتعديل الكامل من صفحة **الإعدادات** دون الحاجة لأي تعديل برمجي (عدد المخالفات، سرعة التكرار، تنوّع الأنواع، وزن كل مستوى خطورة، وحدود التصنيف 🔴🟠🟡🟢).

## ملاحظة حول التكامل المباشر مع البوابة

لا يوجد حاليًا API رسمي عام من بوابة سلطنة عمان التعليمية. صفحة **التكامل** جاهزة كبنية (Mock) قابلة للتفعيل الحقيقي فور توفر API رسمي من الوزارة، دون الحاجة لإعادة بناء المنصة.
